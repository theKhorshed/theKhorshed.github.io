01. about

Full-stack, with a love for the command line.

I'm a software engineer with more than a decade of experience building for the web with PHP and JavaScript, mostly on Laravel and WordPress. I enjoy every step of a feature: modelling the data, designing the API, building the interface, and making sure it stays fast and secure under real traffic.

A long-standing curiosity about Linux and how servers work means I'm as comfortable in a terminal as I am in my editor. I write clean, modular code that follows community standards and proven design principles. Good code should make sense to the next developer without them having to ask.

I'm an open source enthusiast, a long-time *nix fan, and an early adopter who likes trying new tools. When I'm away from the keyboard, you'll usually find me running or out on my bike.
